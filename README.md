# Student Attendance Management System

## Description
A simple Python and SQLite based application for managing student attendance records.

## Features
- Add Student
- Mark Attendance
- View Attendance Report

## Technologies Used
- Python
- SQLite

## Project Structure
student-attendance-management-system/
├── main.py
├── database.py
├── requirements.txt
├── schema.sql
├── data/
└── reports/

## Database Schema

CREATE TABLE students (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL
);

## How to Run
1. Install Python
2. Run database.py
3. Run main.py
4. Use the menu options
